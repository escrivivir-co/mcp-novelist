Instalación Rápida

# Clonar el repositorio
git clone https://github.com/escrivivir-co/mcp-novelist

# Instalar dependencias
cd aleph-mcp
npm install

# Configurar el servidor MCP
cp .env.example .env
# Editar .env con tus credenciales

# Iniciar el servidor MCP
npm run start

Tutorial: Integración con VS Code Copilot

1

Instala VS Code

Si aún no lo tienes, descarga e instala la última versión de Visual Studio Code.

2

Instala GitHub Copilot

Activa la extensión de GitHub Copilot en VS Code y asegúrate de tener una suscripción válida.

3

Configura Aleph MCP

Inicia el servidor MCP siguiendo las instrucciones de instalación anteriores.

4

Conecta VS Code con el Servidor MCP

Edita la configuración de VS Code para apuntar al servidor MCP local.

"github.copilot.advanced":{
  "servers": {
    "AlephAlpha": {
      "type": "http",
      "url": "http://localhost:3066",
    }
  }
}
5

Utiliza las Herramientas Extendidas

Ahora puedes acceder a todas las herramientas personalizadas, incluido el Novelist Assistant, desde Copilot en VS Code.
